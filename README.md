# Julia Viana Diniz Advocacia | Poços de Caldas - MG

Site institucional e de alta conversão da **Dra. Julia Viana Diniz Advocacia**, com escritório sediado na Rua Barros Cobra, n° 667 - Centro, Poços de Caldas - MG, oferecendo assessoria jurídica estratégica presencial e digital para todo o Brasil.

## Desenvolvimento

Inicie o ambiente local:
```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.

## Tecnologias

- Next.js 16 com App Router
- React 19
- Tailwind CSS 4
- Framer Motion
- Lucide React
